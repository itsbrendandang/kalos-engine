# Datasets (not shipped)

No dataset files are kept in this repository. `*.csv` in this folder is git-ignored
so a copy cannot be committed by accident.

The real-data example and tests read `dataset_0.csv` from a folder you point them at:

```bash
export KALOS_DATASET_DIR=/path/to/folder/containing/dataset_0.csv
python examples/real_data_validation.py          # or: --data /path/to/dataset_0.csv
pytest tests/test_real_data_and_mechanistic.py   # data-dependent tests skip if unset
```

Without the variable the example exits with status 2 and a message, and the
data-dependent tests are skipped with the same message. Everything else
(the mechanistic and synthetic tests) runs without data.

## `dataset_0.csv`: provenance and status

- Source: Kaggle "Fermentation optimization" (uploader Aditya Narayan Konwar), listed
  as Apache-2.0 in the uploader's own metadata. The uploader's right to license the
  underlying laboratory runs was **not** verified.
- 715 rows. 696 are flagged `Synthetic` (ML-synthesised) and 19 `Real`. The `Real`
  flag is unverified. Run id `TRICH_15` appears twice with different values.
- Treat the table as a hybrid, semi-synthetic smoke test, not as real data.
  The pool-replay result on it was weak (Spearman 0.048).
- Redistribution status is an owner decision still pending. Do not add the file to
  this repository, and do not publish a copy of it.

## Generated fixtures

The synthetic fixtures (`examples/synthetic_bioprocess/`, `examples/synthetic_scaleup/`) are
not in this folder. They are generated by their `make_synthetic.py` scripts and stay in the repo.
