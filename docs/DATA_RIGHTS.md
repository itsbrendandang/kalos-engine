# Data rights

AGENTS.md rule 3: customer, partner or third-party data is never committed unless its
rights are confirmed here. This file is the written record. A dataset not listed here has
unconfirmed rights: keep it out of the repository and out of published results.

## Owned (rights confirmed by the owner)

Confirmed by the repository owner (Brendan Dang) on 2026-11-21: the project owns these
datasets. Results computed from them (benchmark scores, intervals, rankings) may be
published in this repository.

| Dataset | What it is | Where it is used |
|---|---|---|
| `leadgene_cho_dynamics.csv` (LeadGene / Cytena) | Multi-scale CHO clone data, 504 clones | ML benchmark v2 internal tasks (clone ranking, scale transfer) |
| `anagram_compiled.csv` (Anagram / Bioqore) | Pichia lipase DoE (3 mL bench) and fed-batch runs (3 L to 35 m3) | Real backtest and the Pichia scale task |

The raw files still stay outside the repository and are loaded through
`KALOS_EXTERNAL_DATA` or a path argument. That keeps the repository small and the tests
runnable without them, not because of their rights. Committing them is an owner decision
recorded here first.

Older benchmark results label these tasks "internal, data rights unconfirmed". That label
predates this record; the results themselves are unchanged.

## Generated (part of this repository, Apache-2.0)

`examples/synthetic_bioprocess`, `examples/synthetic_scaleup` and every test fixture are
generated by code in this repository. Synthetic data is always labelled as such and never
enters a user's model as if it were measured (AGENTS.md rule 1).

## Adding a dataset

Add a row here in the same PR that first uses it, with who confirmed the rights, when,
and what may be published. Without a row, load it from outside the repository and keep
its results out of committed files.
